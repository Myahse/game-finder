# Avatar GLB assets

Licensed 3D files only. **Do not commit random downloads.**

Expected layout:

```
base/male-athletic.glb
hair/hair_crop.glb
tops/top_basketball_jersey.glb
...
```

Record every file in `LICENSES.md` (source, license, purchase date, commercial OK).

**Quick start:** open Avatar Creator in dev — a **demo 3D character** loads automatically (no setup).

To use your own art: drop `base/male-athletic.glb` here and set `available: true` in `src/avatar/render/glb/assetManifest.ts`.
